A tiny deterministic program that writes one out-of-office auto-reply, at most 120 characters, as if a houseplant had written it — the plant covering for its absent human, in the plant's own voice.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

It writes the auto-reply to `entry.txt` inside the output directory (or the current directory when `MAKEFUN_OUTPUT_DIR` is unset). No network, no clock, no randomness: the same run always writes the same bytes.
